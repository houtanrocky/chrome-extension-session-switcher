# Chrome Web Store submission files

Each file in this directory maps to a Chrome Web Store dashboard section. Copy the contents without the file's Markdown heading unless the dashboard accepts formatting.

| File | Dashboard use |
| --- | --- |
| `01-name.txt` | Item name |
| `02-summary.txt` | Short description / summary |
| `03-description.txt` | Full description |
| `04-category-and-audience.txt` | Category, language, audience, URLs |
| `05-privacy-disclosures.txt` | Privacy practices and data-use answers |
| `06-permission-justifications.txt` | Permission and host-access explanations |
| `07-screenshots.txt` | Screenshot captions and visual brief |
| `08-whats-new.txt` | Release notes for the update |
| `09-support-and-reviews.txt` | Support response template and review replies |
| `10-seo-and-discovery.txt` | Search terms, page copy, and promotion plan |
| `11-release-checklist.txt` | Final submission checklist |

The copy targets QA testers, developers, support engineers, and product teams testing multiple user roles. It avoids unsupported promises: this is a local convenience tool, not a security sandbox or a replacement for browser profiles.

Update version numbers in all relevant files before each release. Keep claims aligned with the shipped build and screenshots.
